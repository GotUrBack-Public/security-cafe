# Client Security

## Scope
Defensive, transparent browser-security education and passive checks. This is not endpoint protection and must never claim a device is secure.

## Non-negotiable rules
- Never request browser permissions automatically.
- No fingerprinting, persistent identifiers or hidden telemetry.
- No scanning of other origins, local networks, ports or devices.
- Never execute submitted code, HTML, scripts or extensions.
- Label checks as passive, manual or planned.
- Treat browser results as advisory and potentially manipulated.
- Never use client results for authentication or authorization.
- Validate and authorize all sensitive operations on the server.

## Planned areas
Secure-context indicators, CSP education/review, permission and storage hygiene, third-party content boundaries, consent-based report export.
