# Security Café

**Security. Development. Community.**

Security Café ist die Community-Plattform rund um den Twitch-Kanal [GotUrBack04](https://www.twitch.tv/GotUrBack04). Die Website verbindet Livestreams, Community-Einreichungen, öffentliche Code- und Security-Reviews sowie Lerninhalte und eigene Projekte.

## Produktprinzipien

- **Security by design:** sichere Defaults, minimale Rechte und explizite Vertrauensgrenzen.
- **Engineering first:** klare Module, TypeScript, Tests, nachvollziehbare Architektur und Dokumentation.
- **Community with review:** Einreichungen werden moderiert; fremder Code wird niemals automatisch ausgeführt.
- **Transparent:** Review-Status, Methodik und bekannte Einschränkungen werden verständlich kommuniziert.
- **Accessible:** responsive, keyboard-navigierbar und mit ausreichenden Kontrasten.

## Geplante Plattform

- Home – Einstieg, aktuelle Ankündigungen und Highlights
- Live – Twitch-Embed für GotUrBack04, Status und Stream-Informationen
- Submit – sichere Einreichung von Code, Repositories und Websites
- Reviews – veröffentlichte Reviews mit Findings und Referenzen
- Knowledge – Tutorials, Write-ups und Security-Notizen
- Projects – eigene Tools und Open-Source-Projekte
- About – Projekt, Regeln und Kontakt
- Admin – geschützter Moderations- und Content-Bereich
